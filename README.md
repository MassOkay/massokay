**[rag-chunking-study](https://github.com/MassOkay/rag-chunking-study)** — 卒業研究

「LLM による意味境界チャンキングは本当に優れているのか」を検証しました。提案研究として着手しましたが、
自分の予備実験が示した優位がチャンク粒度の交絡だと分かり、比較評価・再検証型の研究に転換しています。
粒度を揃えると LLM の優位は消失し、機械的な等分割が逆転しました。
この否定的結果から、LLM の使いどころを「境界の検出」から「幅の選択」へ再配置しています。
